Node.js, Express, WampServer & MySQL — Setup Guide

1) Node.js Setup install • verify node & npm 
Node.js Setup:
1) Download Node.js from the official website.
2) Install Node.js (npm is included).
3) Verify installation:

node -v
npm -v
2) WampServer Setup install • start • green icon check 
WampServer Setup:
1) Download WampServer from the official website.
2) Install WampServer using the setup wizard.
3) Start WampServer.
4) Check the system tray icon:
   - Green icon = running properly
3) MySQL Setup (via WampServer) open console • create database 
MySQL Setup (Using WampServer):
1) Click WampServer icon in system tray
2) Go to: MySQL > MySQL Console
3) Create a database:

CREATE DATABASE mydatabase;
4) Express Setup install express 
Express Setup:
Install Express using npm:

npm install express

Express is a flexible Node.js framework used to build web applications and APIs.
5) Linking Node.js with MySQL install mysql package 
Linking Node.js with MySQL:
1) Install the mysql package:

npm install mysql

2) Use it to connect your Node.js app to a MySQL database.
6) Using MySQL with Express routes • queries • serve data 
Using MySQL with Express:
1) Create Express routes.
2) Run SQL queries inside routes.
3) Send database results to the client (JSON/HTML).
Example idea:
- GET /users -> fetch users from MySQL -> return as JSON
Explanation (Summary) what each tool does 
Explanation:
- Node.js: runtime to execute JavaScript outside the browser (backend).
- Express: framework to build web servers/APIs quickly using Node.js.
- WampServer: Windows local server bundle (Apache + MySQL + PHP).
- MySQL: relational database used for storing structured data.
- Linking Node.js with MySQL: connect Node app to DB using mysql package.
- Using MySQL with Express: query DB inside Express routes and serve results.
