CSS Selectors universal • type • class • id • attribute 
/* Universal Selector */
* {
  margin: 0;
  padding: 0;
}

/* Type Selector */
h1 {
  font-size: 36px;
  color: #333;
}

/* Class Selector */
.container {
  width: 80%;
  margin: 0 auto;
}

/* ID Selector */
#header {
  background-color: #f4f4f4;
  padding: 10px;
}

/* Attribute Selector */
input[type="text"] {
  border: 2px solid #ccc;
  padding: 8px;
}
Box Model (Concept) content • padding • border • margin
  • Content: The element’s actual data (text/images).
  • Padding: Space between content and the border.
  • Border: The edge around the element.
  • Margin: Space outside the border for spacing.
/* (Concept) Box Model = Content + Padding + Border + Margin */
Box Model (CSS Example) width • padding • border • margin 
.box {
  width: 300px;
  padding: 20px;
  border: 1px solid #333;
  margin: 10px;
}

Responsive Design mobile-first • media queries 
/* Mobile-first approach */
.container {
  width: 100%;
}

@media (min-width: 768px) {
  .container {
    width: 80%;
  }
}

@media (min-width: 1024px) {
  .container {
    width: 60%;
  }
}
Transitions (Hover Effects) transition • hover

button:hover {

Animations (Keyframes) @keyframes • animation

  from { transform: translateX(0); }
  to   { transform: translateX(100px); }
}

.box {
  animation: move 2s infinite alternate;
}
CSS Variables :root • var()

}

body {

  color: var(--text-color);
}
Positioning static • relative • absolute • fixed • sticky 
/* Static */
.static-element {
  position: static; /* Default positioning */
}

/* Relative */
.relative-element {
  position: relative;
  top: 20px;
  left: 30px;
}

/* Absolute */
.absolute-element {
  position: absolute;
  top: 50px;
  left: 50px;
}

/* Fixed */

  position: fixed;
  top: 0;
  left: 0;
  width: 100%;
}

/* Sticky */
.sticky-element {
  position: sticky;
  top: 0;
}
